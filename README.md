# Wedding Save the Date & RSVP Website

A responsive web application designed to serve as a digital "Save the Date" and invitation platform for our wedding. The site provides event details to guests and includes a live form to manage and track RSVP responses automatically.

## Tech Stack
* **Frontend:** Next.js (React framework) for server-side rendering, routing, and responsive UI components.
* **Database / Tracking:** Google Sheets API used as a lightweight database to collect, store, and track guest RSVPs in real time.

## Features
* **Event Information:** Clean interface displaying the date, schedule, location, and venue details.
* **Automated RSVP:** Guests can submit their attendance status directly through an online form, which instantly populates a centralized tracking sheet.
* **Responsive Design:** Optimized for seamless viewing and submission across mobile devices and desktops.
